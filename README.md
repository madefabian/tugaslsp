Simple Company Profile

Website company profile sederhana yang berisi informasi singkat tentang perusahaan, layanan, dan kontak untuk memudahkan pengunjung mengenal perusahaan.

---

## 🚀 Fitur

Halaman Beranda (Home)
Halaman Profil Perusahaan (Tentang Kami)
Informasi Layanan / Jasa
Halaman Kontak
Informasi Alamat & Jam Operasional
Navigasi Sederhana & Mudah Digunakan

---

## 🛠️ Teknologi yang Digunakan
- HTML / CSS / JavaScript  
- PHP / Laravel  
- MySQL  
- Filament
- Tailwind
